# Чат-сервер на TCP-сокетах

## Формат сообщения
Сообщения передаются в формате `COMMAND + LENGTH + DATA`.
`COMMAND` занимает 4 байта и определяет тип сообщения, а `LENGTH` — 4 байта и содержит размер следующих за заголовком данных.
Благодаря `LENGTH` получатель знает, сколько байт нужно прочитать из TCP-потока для получения одного сообщения.

## Поддерживаемые команды
`JOIN` — подключение пользователя, `TEXT` — отправка сообщения, `LIST` — получение списка пользователей, `QUIT` — выход из чата.
`ERRO` — сообщение о неизвестной команде. Используется вместо `ERROR`, так как поле `COMMAND` в моём формате занимает ровно 4 байта.
